## 🚀 Step-by-Step Deployment

### Part 1: Deploy Backend to Railway.app

#### Step 1: Create Railway Account
1. Go to [railway.app](https://railway.app)
2. Sign up with GitHub (free)
3. Verify your account

#### Step 2: Deploy Backend
1. Click **"New Project"** → **"Deploy from GitHub repo"**
2. Connect your GitHub account
3. Select your `cinemizer` repository
4. Railway will auto-detect the `railway.json` configuration

#### Step 3: Configure Environment Variables
In Railway dashboard, add these variables:

```bash
# Required API Keys
GOOGLE_API_KEY=your_google_api_key
GEMINI_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key
TMDB_API_KEY=your_tmdb_api_key
OMDB_API_KEY=your_omdb_api_key
PINECONE_API_KEY=your_pinecone_api_key

# Optional
DEEPGRAM_API_KEY=your_deepgram_api_key
HUGGINGFACE_API_TOKEN=your_hf_token

# Database (auto-generated by Railway)
DATABASE_URL=sqlite:///./app.db

# Authentication (generate a random string)
AUTH_SECRET_KEY=your_random_secret_key_here
```

**Generate AUTH_SECRET_KEY:**
```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

#### Step 4: Get Your Backend URL
1. After deployment, Railway will provide a URL like:
   ```
   https://cinemizer-production.up.railway.app
   ```
2. **Copy this URL** - you'll need it for frontend

#### Step 5: Verify Backend is Running
Visit: `https://your-backend-url.up.railway.app/health`

Should return:
```json
{
  "status": "healthy",
  "message": "Movie Companion API is running"
}
```

---

### Part 2: Deploy Frontend to Vercel

#### Step 1: Create Vercel Account
1. Go to [vercel.com](https://vercel.com)
2. Sign up with GitHub (free)

#### Step 2: Import Project
1. Click **"Add New"** → **"Project"**
2. Import your `cinemizer` repository
3. Configure project:
   - **Framework Preset**: Next.js
   - **Root Directory**: `frontend-next`
   - **Build Command**: `npm run build`
   - **Output Directory**: `.next`

#### Step 3: Configure Environment Variables
In Vercel project settings → Environment Variables:

```bash
NEXT_PUBLIC_API_BASE_URL=https://your-backend-url.up.railway.app
NEXT_PUBLIC_DEMO=0
```

**⚠️ Important:** Replace `your-backend-url.up.railway.app` with your actual Railway backend URL!

#### Step 4: Deploy
1. Click **"Deploy"**
2. Wait 2-3 minutes for build to complete
3. Vercel will provide a URL like:
   ```
   https://cinemizer.vercel.app
   ```

#### Step 5: Test Your Deployment
1. Visit your Vercel URL
2. Try the chat feature
3. Check if API calls work (login, chat, recommendations)

## 🔄 Alternative: Deploy Backend to Render.com

### Deploy to Render.com (Alternative Option)

#### Step 1: Create Render Account
1. Go to [render.com](https://render.com)
2. Sign up with GitHub (free)

#### Step 2: Create Web Service
1. Click **"New"** → **"Web Service"**
2. Connect your GitHub repository
3. Configure:
   - **Name**: `cinemizer-backend`
   - **Environment**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT --workers 2`
   - **Plan**: Free

#### Step 3: Add Environment Variables
(Same as Railway - see above)

#### Step 4: Deploy
1. Click **"Create Web Service"**
2. Wait 5-10 minutes for first deployment
3. Get your backend URL: `https://cinemizer-backend.onrender.com`

**⚠️ Note:** Render free tier spins down after 15 min inactivity and takes ~50 seconds to wake up.

## 🌐 Update Frontend to Use Backend URL

After deploying backend, update Vercel environment variables:

1. Go to Vercel Dashboard → Your Project → Settings → Environment Variables
2. Update `NEXT_PUBLIC_API_BASE_URL` with your backend URL
3. Click **"Redeploy"** to apply changes

## 🐛 Troubleshooting

### Backend Issues

**Problem: Backend returns 500 error**
- Check environment variables are set correctly
- View logs in Railway/Render dashboard
- Verify all required API keys are valid

**Problem: Database connection error**
- Railway: Use SQLite (`DATABASE_URL=sqlite:///./app.db`)
- Render: Enable persistent disk in settings

**Problem: Cold start is slow**
- Railway: Normal (5-10 seconds)
- Render: Expected on free tier (30-60 seconds)

### Frontend Issues

**Problem: API calls fail (CORS error)**
- Verify `NEXT_PUBLIC_API_BASE_URL` is set correctly
- Ensure backend CORS is configured (already done in `main.py`)
- Check backend is actually running

**Problem: Build fails on Vercel**
- Check `package.json` in `frontend-next` directory
- Verify Node.js version compatibility
- Check build logs for specific errors

**Problem: Environment variables not working**
- Vercel: Must start with `NEXT_PUBLIC_` for client-side
- Redeploy after changing environment variables
